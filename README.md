# Aldi QA Portfolio

A simple IT Quality Assurance portfolio built with Next.js.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Before deploying

Update these links/placeholders in `app/page.tsx`:
- Email
- LinkedIn
- GitHub
- Project GitHub links

Then push the project to GitHub and import the repository into Vercel.

## Notes

The portfolio uses sample/practice project descriptions. Replace them with your actual public projects, screenshots, test reports, and repository links. Do not publish confidential client information, credentials, internal URLs, or proprietary documents.
